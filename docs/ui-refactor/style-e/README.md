# Style E UI reskin: mockups and directions tried (issue #261, ADR 0220)

*2026-10-28. Static mockups only, nothing built. Everything here is kept so a later thread can come back to any direction.*

Each direction is **one stylesheet laid over the real game** (same layouts, same screens), drawn with
`npm run shots -- --style`. Only the look changes, as the reskin rule says. References and the analysis of
Skull and Bones, Sea of Thieves, Seafarer and Pokemon Legends Z-A: [references.md](references.md).

## Rules learned from Guillaume's feedback (keep for any later round)

- No red confirm, buy or sail buttons. Red stays for danger (New game) and the edge buoys (art bible).
- No ruled lines, plank seams or stripes on backgrounds: they hurt readability. Flat paper, a soft edge at most.
- Avoid the default blue-and-gold look: no yellow or bright blue accents; teal or hull blue must stay muted and be judged on the sheet.
- Kept from what he liked: A's personality (paper, serif, ink), B's HUD, direction 1's menu column and brown leather.
- Show every visual to him before anything is validated; compare against "today" side by side.

## Redraw

```sh
sh build-fonts.sh                       # css/fonts.css (Fraunces, inlined; git-ignored, needs ../mockups/src/fonts)
sh shots.sh f-final desktop,portrait    # the 9 screens + 2 night shots to /tmp/claude-0/s/f-final (any css/<name>.css)
sh extra.sh                             # refined only: component strip, rules sheet, pennants
python3 sheets.py <shots dir> <out dir> f-final="Final"       # contact sheets
python3 compare.py <shots dir> out.jpg d1-paper f-final desktop "left label" "right label"
```

Other scripts: `compare3.py` (three-way), `refined_sheets.py` (the refined review set), `js/strip.js` and `js/rules.js`
(a component strip and a rules sheet drawn into the game page).
The stylesheets are mockup code (`!important` everywhere to win over today's rules). The build would move tokens into
`src/ui/theme.css` and the materials into small SVG frames; see ADR 0220 and the plan.
