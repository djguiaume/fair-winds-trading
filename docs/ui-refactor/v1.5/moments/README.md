# Moments and feedback (#442, decision 0274)

Sheets of the build, one round, desktop and phone landscape. The sea shots are the real game (`npm run shots`); the banner was shown by a script because the shot tool's clock does not sail the boat in (the arrival check itself is tested in `tests/ui-moments.test.ts`). The strip is the editors' Theme page (`#ed-theme`), which now shows the moments by day and by night.

| File                         | Shows                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------ |
| `arrival-desktop.jpg`        | The arrival banner at Saltmere: name in IM Fell, tagline under it              |
| `arrival-phone-landscape.jpg`| The same on a phone held sideways (smaller, lower)                             |
| `strip-day-night.jpg`        | Banner, "Horn in 10", the stamped card and the finish board, day and night     |
| `settings-motion.jpg`        | Settings › Display › Interface motion: Full, Reduced, Off                      |

Sounds: `npm run sound -- effect ui-press` (also `ui-confirm`, `ui-back`, `ui-tab`, `ui-error`, `ui-coin`, `ui-stamp`, `ui-arrival`, `ui-sting`).
