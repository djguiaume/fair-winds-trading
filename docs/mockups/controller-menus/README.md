# Controller focus in the menus (decision 0163)

Mockups drawn in the real game by `npm run shots` with this folder's styles and scripts:

    npm run shots -- --list docs/mockups/controller-menus/src/shots-a.json --out shots/pad
    python3 docs/mockups/controller-menus/src/sheets.py shots/pad docs/mockups/controller-menus

- `a-*.png` brass ring with a soft glow, `b-*.png` lifted plate with a brass edge, `c-*.png` thin
  line plus a brass pointer beside the control.
- `*-desktop.png`: title menu, Settings, port market, Quay quest card, build spot choice (EN).
- `*-phone.png`: title menu and Settings in portrait, market in landscape (FR).
- The button hints pill (A Choose, B Back, LB RB Tabs) is the same in all three.
