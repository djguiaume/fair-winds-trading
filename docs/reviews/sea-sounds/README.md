# Sounds of the sea: review set ([0209](../../decisions/0209-sounds-of-the-sea.md))

Rendered by `npm run sound` with the game's own code; nothing downloaded or bought. Every effect, the
port bells and the themes are left out of the repository to keep it light: `npm run sound -- tour`
makes the whole set (49 files, about 18 s) in `shots/sounds/`.

- `sea-<id>.mp3`: 20 s of each sea's bed, every call allowed, wind 12 kn, speed 5 kn.
- `north-gale-luffing.mp3`: 22 kn, in irons with sail up.
- `east-stormbreak-rain-far-from-fogwatch.mp3`: a squall, rain, thunder, the far foghorn.
- `south-open-sea-light-wind.mp3`: light wind away from reefs and shores.
- `settings-sounds-*.png`: the Sounds volume in Settings. `sounds-page-north-desktop.png`: the
  editors' Sounds page.

The art director's asks per sea are in the decision's context.
