# v1.9 towns 3: the far-sea towns (after)

Issue #515. The nine far-sea towns pass every town rule (decision [0301](../../../decisions/0301-town-layout-rules-and-the-believable-town-check.md)): `npm run island -- audit` shows 0 fails and 0 warnings on each (before: 32 fails, 81 warnings). Every change was made with `npm run island` steps (the `move` step turns or moves a prop, pier or lane in place). No island, port or signature place moved or changed name; no town level changed.
