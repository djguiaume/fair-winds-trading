# Founding an outpost: Palm Key

**Decision:** [0155](../../decisions/0155-founding-an-outpost.md) (Proposed until Guillaume has seen these). Real captures of the south sea (`?map=phase4`), made with `src/capture.cjs` against `npx vite --port 5199`. The outpost's town is placed with existing props only (beach houses, drying racks, crates, lamp post, warehouse, the epilogue's flagpole and name board); its layout is new.

## Before founding: an empty island

Palm Key is not a port yet: no pier, no market, no name on the chart, only its stone daymark and palms.

![Palm Key before founding](palm-key-site.png)
![The chart before founding](chart-site.png)

## Founded: a hamlet (level 1)

The flagpole and name board, two homes, crates and a spice drying rack by the new pier. Palm Key goes on the chart as a port and starts gathering spice.
