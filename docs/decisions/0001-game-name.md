# 0001. Name the game "Fair Winds Trading"

**Status:** Accepted, 2026-10-19

**Context:** The game needed a name before creating the repository. Shortlist: Tradewind Isles, Leeward, Saltroute, Beam Reach, Fair Winds Trading Co.

**Decision:** Guillaume chose **Fair Winds Trading**, repo slug `fair-winds-trading`.

**Consequences:** The name points at both wind-driven sailing and trade, with a cozy merchant-company feel.
