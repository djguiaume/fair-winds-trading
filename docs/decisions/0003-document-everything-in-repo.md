# 0003. Keep all docs, decisions, code and assets in this repo

**Status:** Accepted, 2026-10-19

**Context:** Guillaume asked that documents, planning, decisions, code and assets all be committed to the repository, and that work is always documented.

**Decision:** Planning lives in `docs/`, decisions in `docs/decisions/`, reference art in `docs/reference/`. Every notable choice gets a decision record.

**Consequences:** The repo is the single source of truth for the project.
