# Agent command-line tools

Moved here from CLAUDE.md (decision 0153). Every tool takes `--help`; `npm run fw` lists them. If a tool lacks something, add it to the tool (and move the logic into the shared module the editor uses) rather than writing a one-off script.


Agents write the data files directly, then use these tools instead of writing one-off scripts. They run the game's and the editors' own code (loaded through Vite), print a short result, and take `--help`.

- `npm run check`: every content check the editors run (seas, island files, quests, perks, controls) in about 10 s. Run it after editing any data file, before the full `npm test`. `--only islands --island sunreach`, `--map file.json` for an editor export, `--controls file.json` for a controls page export, `--fast` skips route sailing, `--warnings`, `--json`.
- `npm run adr`: the next free decision number across main **and every pushed branch**. `npm run adr -- new "Title"` writes the file and its README line. Use it instead of guessing the number.
- `npm run balance`: the balance bots on all three difficulty levels (Guillaume's rule) in about 10 s (still on the ring alone by default until the bots open the seas in story order, 0198; `--map phase4` for the game's sea): leg times, milestones per level and the failing checks. `--legs` for leg times only, `--map file.json`, `--all`, `--json`. Run it after changing prices, ships, wind or the map.
- `npm run island`: make and change island files with the island builder's own edits, instead of a generator script. `npm run island -- new palm-key --style tropic --seed 7103 --blob r=1,stretch=1.25`, then one step per call (`plateau --at x,z --size rx,rz`, `mountain`, `lake`, `islet`, `ramp --points "x,z x,z"`, `lane`/`path`/`stairs`, `woods --at x,z --r 0.3` (`--density d`: the new look's forest; `--grove`: woods only the new look grows), `spot`, `prop palm --at "x,z x,z" --level 2`, `pier`, `remove prop 3`, `set`, `tidy`) or many at once with `--steps steps.json` (steps as data, `src/editor/island/steps.ts`). It writes the file the way the builder exports it, runs the builder's checks at the island's size on the seas (`--radius` for an island not on a sea yet) and prints one line. `--dry`, `--warnings`, `--json`, `--forest [--level n]` (the new look's trees by kind and per quality level). Add the island to its sea file yourself. Terrain (decision 0234, sculpting 0232): `npm run island -- <id> sculpt raise|lower|flatten|smooth|slope --at "x,z x,z" --brush r --strength s` (`--height h` for flatten, `--from x,z,h --to x,z,h` for a slope, `--falloff`, `--override` to edit the ground kept level round buildings), `sculpt list|remove <n>|reset`, `sculpt export [--to file]`, `sculpt import file [--append]`. Same code as the builder's brushes; places are island-radius units in the file's frame (z toward the harbour). Sample: [docs/tools/terrain.md](docs/tools/terrain.md). The builder's Terrain tab makes the same edits: [docs/island-builder/builder/terrain.md](docs/island-builder/builder/terrain.md).
- `npm run sea`: the Phase 4 sea's files (`src/data/seas/*.json`, `grown.json`) with the sea editor's own edits (decision 0161), instead of a generator script. `npm run sea -- list`; `new north --name "…"`; `add island|reef|sandbank|shallows|ridge|mark|current|drift|zone|area|edge|port --sea south --at x,y` (`edge`: open water joined to the round sea, the edge buoys follow it, decision 0202) (`--outline`, `--path`, `--type cardinal-north`, `--kind cold-gale`, `--max-draft`, `--name`…); `move <what> <id|index> --at|--by|--to-sea`; `set <what> <id> --field …`, `set grown --radius`; `remove`; `--steps steps.json` (steps as data, `src/editor/seaSteps.ts`). Writes every changed file byte for byte like the editor's export, runs the map checks (`--routes` adds the route checks, ~6 s), prints one line. `--dry`, `--json`, `--warnings`. `npm run sea -- density`: how full each sea's quarter is (decision 0180; target no empty disc over r150, at most ~12% empty water, one open reach). `npm run sea -- calm [--at "x,y x,y"]`: how much of the open sea's swell and chop the coast leaves at each port's berth or at these points, from the game's own bake (decision 0248, `waves.json` › `coast`). `npm run sea -- drawn`: per quality level and review sea, how far the drawn sea can stand from the one boats float on (the waves its grid only shades, and its sag; decision 0249). `npm run sea -- drag`: how much the waves slow each ship by review sea and point of sail (decision 0256, `waves.json` › `drag`). `npm run sea -- waves [path=value …]`: every ocean control by what it changes (sailing: the waves' drag; sea, drawing, comfort, level defaults, review seas), and sets them with the `?tune` panel's own edits, e.g. `waves waves.motion.gentle=0.3 graphics.quality.low.waves=true` (decision 0250).
- `npm run chart`: the labelled map (PNG + SVG) Guillaume must see with every map or layout change, drawn by the map editor's chart code from the real map and island files: coasts, ports and names, reefs, banks, shallows, sea marks, currents, wind zones, a legend panel. `--sea phase4|ring|stress|file.json` (default phase4, the game's own grown sea since 0198; an editor export, or a sea file merged round the ring), `--around sunreach --radius 300` or `--view w,s,e,n`, `--route start,sunreach` sails a leg with the route checks' planner, `--density` shades empty water, `--overlay file.json` adds proposed islands, areas, routes and labels ([docs/tools/chart.md](docs/tools/chart.md)), `--coast` (the sailed and the drawn coast, red where they part, decision 0237), `--out path`. Use it instead of a drawing script.
- `npm run shots`: real-game screenshots in one line, instead of a Playwright script (it starts Vite and Chromium itself, gets past the menu, level card, tutorial offer and harbour). `--sea phase4|ring|stress|map.json` (default phase4, the game's sea, 0198; `ring` = the ring alone at `?map=ring`), `--island a.json` (builder exports), `--at x,y --heading --zoom --look x,y --yaw deg --tilt deg` (a turned camera, 0223), `--look v2` or `--look v2,x,y` (the v1.2 ground from the shared height field, `?look=v2`, 0222), `--sail --ship --hold ArrowUp:2000 --click sel` (several: `"#a;#b"`), `--focus sel --style a.css --script a.js` (a mockup drawn in the real game, 0163), `--pad "lx=0.8:1500,rb:100,y:100"` (a fake game controller, 0162), or `--port id --tab quay`, `--moor skerry` (`--offer spot-2`, `--built spot-1=workshop`, `--island-tab`, `--choose spot-2`: Skerry's plots and Island tab, 0210), `--quest rooks-thanks:skerry`, `--chart --charted`, `--menu` (the title menu), `--prologue` (a new voyage's start as a player who skips the tutorial meets it, 0160; otherwise the tools start in plain free play), `--town palm-key:2` (a town's level; an empty island is founded first, 0157), `--lang fr`, `--night`, `--storms`, `--no-zones`, `--no-currents`, `--sizes desktop,landscape,portrait`, `--out dir` (default `shots/`, ignored by git), `--save-link` (also prints the scene as a Pages save link to play from). Many shots: `--list shots.json`, a JSON list whose entries take the same options as keys. Look at every image before posting it. The map editor: `--editor phase4|ring --select island:sunreach --look x,y --zoom upp --export --draft file.json`.
- `npm run quest`: `quest list`; `quest check <id>` (the quest builder's checks on that quest, `--file q.json` for a quest not in `src/data/quests` yet); `quest play <id> --step N` prints the builder's play-from-step link (local and Pages), `--sea` starts near the step's place, `--shots` takes the screenshots of that test with the `shots` options. The quest's own sea (0164), with the builder's edits, written as the builder exports and checked: `quest move <id> --step N --at x,y --heading deg` (where the step takes the boat), `quest buoy <id> --at x,y --name A` (`<n> --at|--name|--type|--remove`), `quest wind <id> [--step N] --speed 10 --from 30` (`--clear`), `--dry`.
- `npm run review`: the v1.2 island acceptance sheets (#277): per island one JPG with the new look at High and Low from the same pose and the `--coast` chart under it. `--sea ring|south|north|west|east` or ids (`calda,saltmere`), `--zoom z`, `--night`, `--quest id:step` (an island that only stands after a quest, e.g. Cinder Isle: `outpost-west:supplies`), `--no-shots` (redo charts and sheets from the shots in `--out`), `--out dir` (default `output/review`). List and status: [acceptance.md](docs/reviews/art-direction/new-look/acceptance.md).
- `npm run race`: the regatta's races (decision 0217), the quest builder's race edits: `race` lists them; `race <id>` its course and medal times; `--pars --write` (`--all`) has the balance bots sail it with every ship on all three levels and writes the pars; `--start "x,y x,y"`, `--finish`, `--add --at x,y`, `--mark N --at|--remove`; `--storm --at x,y [--radius --strength --drift deg --speed]` adds a race's own storm (decision 0225; `--storm N` changes it, `--storm N --remove` removes it; the pars are the slower with and without them); `--overlay file.json` writes the course for `npm run chart -- --overlay`; `race rules`, `race set medals.silver 1.2`, `race series <id> --name --pennant`, `race flag <id> --shape --bands --length --height|--remove` edit `regatta.json` and `flags.json` as the editor's Regatta page does. Re-run the pars after changing a course or the map round it.
- `npm run cosmetics`: the boat cosmetic catalogue (decision 0261), the editors' Cosmetics page's own edits: `list [slot]`, `check`, `add <slot> <id> [--en --fr --unlock free|quest:id|regatta:id|milestone:name --classes a,b --svg file --recipe prop-id --tris n]`, `set <slot> <id> <path> <value>` (`cloth`, `colours "#a,#b"`, `unlock.quest`, `own.bands`; `-` clears), `remove`, `export [--out file]` and `import file` (one bundle of items and emblem SVGs), `shot <slot> <id> [--class sloop]` and `sheet [--slot s]` (flat SVG previews into `shots/cosmetics`), `--dry`. Written byte for byte as the page exports them, then checked. How to add one: docs/content/cosmetics.md.
- `npm run free`: the Free Sailing presets (decision 0266), the editors' Free Sailing page's own edits: `list [--json]`, `check`, `add <id> [--from id]`, `set <id> <field> <value>` (`name.en`, `place.x`, `hour`, `weather`, `ship.class`, `ship.sails` …), `remove`, `--dry`. `walk [--shots dir]` is the isolation proof in the real game: a voyage, then Free Sailing launched, dressed, changed, paused, restarted, refreshed and left; it fails if the voyage's save or any non-preference storage changed. How to add one: docs/content/free-sailing.md.
- `npm run identity` (v1.5, #439): the logo symbols in the index.html sprite come from `tools/fw/identityLogo.mjs`: `identity sprite` writes them between the identity markers (`--check` only compares), `identity icons` renders `public/favicon.svg` and the PNG icons (apple touch, 192, 512, maskable) from them, `identity sheet` makes the one-sheet (logo on paper and on the scene, every sprite icon at 16, 24 and 32 px on paper and ink, type) into `shots/identity`.
- `npm run sound`: the game's sounds into MP3s (decision 0209), rendered with the game's own synthesisers, sea beds and composer, instead of a script: `sound list`, `sound check`, `sound effect gull --pitch 1.3`, `sound bell skerry` (a port's dock bell), `sound sea north --secs 30 --wind 18 --speed 6 --luff --rain 0.8 --storm --docked --far`, `sound music regatta --secs 60`, `sound mix north` (a sea with its theme at the default volumes), `sound tour` (every sea, effect, bell and theme: the review set). `--file audio.json` plays a Sounds page export, `--out dir` (default `shots/sounds`), `--wav`. The editors' Sounds page edits `src/data/audio.json` with a play button on everything.
- `npm run fw -- editorperf`: how fast the island builder's terrain brushes are on the largest island (dab, stroke finish, undo/redo, save/reload, heap), CPU only; `--island id`. Results: [docs/reviews/new-look-performance](../reviews/new-look-performance/README.md). Browser frame reports: `PERF_QUALITY=low|medium|high|ultra npm run perf -- 'http://127.0.0.1:5180/?look=v2' out.json` ([tools/performance](../../tools/performance/README.md)); the render budget has its own limits for the new look.
- `npm run fw`: lists every tool (the seven of 0153, and `sea` from 0161).
